# City Taxi Simulator

Drive a yellow taxi through the hilly streets of Istanbul's Galata and Karaköy. Pick up passengers, follow the GPS, obey the traffic lights and tune your cab in the workshop.

**Play:** https://kam-karma.github.io/city-taxi-simulator/

Controls: W/A/S/D or arrow keys to drive, Space handbrake, H horn, C camera, Esc pause. On phones and tablets: on-screen steering wheel (or tilt) and pedals.

This repository holds the built game only.
